# Milestone 0 Decision

## Outcome

Milestone 0 is operationally passed with caveats.

Validated:

- Python/MLX dependencies install locally.
- Node/promptfoo installs locally.
- `Qwen/Qwen3-1.7B-MLX-4bit` downloads into the project-local Hugging Face cache.
- `mlx_lm.server` can serve an OpenAI-compatible endpoint on `localhost`.
- `promptfoo` can run one local sanity prompt, apply narrow EOS-residue normalization, and save output.
- `scripts/timing` can measure streaming TTFT and total generation time.
- `scripts/eval` disables promptfoo cache for sanity runs so verification uses live model output.
- `scripts/serve-model` can pass a canonical chat template file and chat-template args through to `mlx_lm.server`.

## Caveats

- MLX commands need to run outside the sandbox because importing MLX requires normal Metal access.
- The Qwen3 conversion's embedded chat template ignores `enable_thinking=false` because it lacks that branch; the workspace overrides it with `evals/chat_templates/qwen3.jinja`.
- Raw server output can still include visible EOS markers such as `<|im_end|>` due to an upstream `mlx-lm` EOS trimming bug.
- promptfoo output normalization strips only the remaining trailing `<|im_end|>` residue.
- `mlx-vlm` was installed but not yet validated as a serving path.
- promptfoo local viewer/offline behavior is not fully checked yet.

## Next Decision

Proceed to candidate scouting and cross-review for 2-3 real benchmark candidates, but keep the Qwen 1.7B model as a bootstrap/runtime smoke-test model rather than a quality benchmark default.
