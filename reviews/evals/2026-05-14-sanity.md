## Quality Notes

The first runs exposed two separate issues:

- The MLX conversion's embedded chat template omitted the Qwen3 `enable_thinking` branch, so `enable_thinking=false` was a no-op.
- `mlx_lm.server` leaves visible EOS text such as `<|im_end|>` in output because EOS handling pre-empts user stop-word trimming.

The current server uses the canonical upstream Qwen3 chat template from `evals/chat_templates/qwen3.jinja` with `enable_thinking=false`. That fixes the thinking-token issue at the source. The promptfoo transform now strips only the trailing `<|im_end|>` residue.

The no-cache canonical-template verification run showed clean promptfoo output:

`The ocean covers over 71% of Earth's surface and plays a vital role in regulating the climate and supporting diverse ecosystems.`

Raw timing output also showed no `<think>` block after the template override. Keep the narrow `<|im_end|>` transform until the upstream `mlx-lm` EOS trimming bug is fixed.
