## [0.3.1] - 2026-11-22

  - Bumped `TESTED_OPENCODE_VERSION` to `"2.3.2"`, disabled embedded `opencode-pty` extraction via `OPENCODE_PTY_BIN` sentinel + Seatbelt exec deny (fast direct shell fallback), hard-denied `browser` and `execute`, removed `--variant` from worker `run` flags, reserved/unset `2.3.2` env vars (`OPENCODE_CLI_CONFIG_CONTENT`, `OPENCODE_PTY_*`, `OPENCODE_DB`), rejected `--server` unconditionally, blocked `api`/`plugin`/`reload`/`mcp` in interactive mode, pinned an immutable per-run binary copy in `scripts/opencode-smoke` for truthful version attribution, and updated the `README.md` Quick Start prerequisite to `v2.3.2`.
- **Privatemode upstream catalog sync and strict YAML alias handling (`local_assist/catalog_sync.py`, `local_assist/_miniyaml.py`, `scripts/sync-model-catalog`, `.github/workflows/catalog-sync.yml`, `tests/test_catalog_sync.py`, `tests/fixtures/privatemode_v1_64_0/`)**: Added Privatemode upstream release/deployment/model catalog drift checks (`--privatemode-tag`, strict ConfigMap YAML anchor/alias validation matching PyYAML 6.0.3, and atomic catalog healing with proof reverification).
