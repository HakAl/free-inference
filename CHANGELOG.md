# Changelog

All notable changes to `free-inference` are documented in this file.

## [0.1.3] - 2026-11-08

### Security, Spend Ceiling Enforcement, and Key Sealing Hardening
- **Multi-completion spend ceiling clamp (`tools/se_key_proxy/main.swift`, `local_assist/security_profile.py`, `SECURITY.md`)**: Clamped `n` to `1` and `best_of` to `1` in both `se-key-proxy` (`clampMaxTokensIfNeeded`) and `_WorkerTokenRelay` (`_clamp_max_tokens`), and stripped `maxOutputTokens` in `_WorkerTokenRelay` (matching `se-key-proxy`), preventing `n > 1` or `best_of > 1` payloads from multiplying per-request completion billing beyond the worst-case session USD ceiling (`--max-session-usd`).
- **`se-key-proxy seal` debugger protection, raw buffer zeroing, and atomic binary staging (`tools/se_key_proxy/main.swift`, `local_assist/se_key.py`)**: Enabled `disableDebuggerAttachment()` (`PT_DENY_ATTACH`) at the start of `runSeal()`, replaced String-copying input reads with mutable byte buffers zeroed via `bestEffortZero` (`Data.resetBytes(in:)` and explicit scratch-buffer zeroing in `trimASCIIWhitespaceAndZero`) in `readAllFromFD` and `readSecretFromTTY`, and updated `build_se_key_proxy` to compile and `codesign` into a unique staging file (`.se-key-proxy-build-*`) before atomic `os.replace` so running `se-key-proxy` processes are never mutated in place (`ETXTBSY` / `SIGBUS`).
- **Deprecated and archived model enforcement (`local_assist/registry.py`, `local_assist/launch.py`, `scripts/opencode-local`, `scripts/opencode-attested`)**: Enforced `VALID_MODEL_STATUSES = {"active", "runnable", "reviewed", "candidate", "archived"}` and `deprecated`/`deprecation_date` validation in `resolve_endpoint`, unconditionally blocked `status: archived` models at launch, and blocked models with `deprecated: true` or a `deprecation_date` (such as `tinfoil-kimi-k3`, scheduled for upstream deprecation `2026-11-12`) unless `--allow-deprecated-model` is explicitly passed.

### Model Catalog Self-Healing and Hardening
- **Self-healing model catalog (`local_assist/catalog_sync.py`, `scripts/sync-model-catalog`, `.github/workflows/catalog-sync.yml`)**: Added `./scripts/sync-model-catalog` (`--check`, `--apply`, `--json-out`, `--markdown-out`, `--reconcile-github-issue`, `--attempt-id`) to verify registered Rung 1 (`local` Hugging Face) and Rung 2/3 (`tinfoil` attested enclave) models against live upstream router manifests (`https://inference.tinfoil.sh/.well-known/tinfoil-proxy`), Sigstore-backed enclave release metadata (`tinfoilsh/confidential-*`), `tinfoil-config.yml`, Tinfoil's pricing page, and Hugging Face API metadata.
- **Fail-closed weight-drift demotion, feed-disagreement ordering, and status ratchet**: Checked `/v1/models` presence before `healthy <= 0` so an already-demoted model missing from `/v1/models` raises a `FeedDisagreementItem` instead of silently returning clean, added symmetric unregistered model disagreement checks in both directions (`router_manifest` vs. `/v1/models`) with pre-disagreement catalog ID/repo collision rejection (`registered=False`), bound `quarantine_disagreement` strictly to registered Tinfoil-managed entries with a matching `served_model_id`, enforced a one-way status ratchet (`active/runnable -> reviewed/candidate -> archived`) so archived models are never resurrected to `candidate`, recorded `quarantine_disagreement` mutations in `report.updated_models` (`check_status: "quarantined"`), tightened `ENCLAVE_REPO_RE` (`^tinfoilsh/[A-Za-z0-9][A-Za-z0-9._-]{0,99}$`), `SERVED_ID_RE`, and `WEIGHTS_SOURCE_RE`, rejected `NaN`/`Infinity`/`1e999` JSON constants across all upstream feeds and catalog healing, capped `host_code_tags` (`<= 8`) and `tinfoil-config.yml` fetches (`<= 32`), preserved `models.yaml` file permissions across atomic writes, and bounded `render_github_issue_body` (`<= 60000` chars).
- **Weekly GitHub Actions drift monitor (`.github/workflows/catalog-sync.yml`)**: Added a scheduled weekly and `workflow_dispatch` job (`timeout-minutes: 5`) on `HakAl/free-inference` that runs `./scripts/sync-model-catalog --check` with per-run `--attempt-id` and `markdown_sha256` output binding and automatically opens, updates, or closes a `[catalog-drift]` tracking issue without auto-committing to `main`.
- **Kimi K3.1 Pro (`tinfoil-kimi-k3-1-pro`) Rung 3 evaluation and catalog refresh (`models.yaml`, `docs/attestations/2026-10-31-tinfoil-rung3-trial.md` Section 8)**: Evaluated `tinfoil-kimi-k3-1-pro` (`moonshotai/Kimi-K3.1-Pro@6d0a0202956796543364d666ab19c6ad1a494ee1`, `dmverity:sha256:8d9c355a94e60f43598713759028328bbe795336f2700799d0ff4f3898e785e0`, `$4.00 / $20.00` per 1M tokens, `$0.40` cached) across all 4 gates (`sanity` `1/1`, `v1` `9/10`, `tools` `4/4`, `opencode-smoke` `PASS` in `2.5669s`, `$0.1646` total spend across `29,382` tokens, `0` session token leaks), updated `tinfoil-deepseek-v4-1-flash` to `v0.0.10+b200` / `v0.0.10+b300` (`$0.60 / $1.45` per 1M tokens, `$0.01` cached), and recorded `deprecation_date: "2026-11-12"` (`v0.0.16`, `$0.60` cached) on `tinfoil-kimi-k3`.

### Setup Modes, Launcher Unification, and Release Plumbing
- **Minimal setup modes (`scripts/setup`, `requirements-local.txt`)**: Added `./scripts/setup --launcher-only` (`--proxy-only`, 0 Python/Node packages; builds `bin/se-key-proxy` and verifies `bin/tinfoil-proxy` using stdlib Python 3.11+) and `./scripts/setup --local-only` (`requirements-local.txt`, 35 pinned packages for `mlx-lm==0.31.3`, `PyYAML==6.0.3`, and `hf_transfer==0.1.9`, excluding `mlx-vlm`, `mlx-audio`, `opencv-python`, `scipy`, `pandas`, `pyarrow`, and `datasets`, and skipping `npm ci`).
- **Shared launcher module (`local_assist/launch.py`, `scripts/opencode-local`, `scripts/opencode-attested`)**: Extracted shared CLI parsing, worker security profile resolution, lifecycle status checks, environment allowlisting, OpenCode service sync, and Seatbelt worker session execution into `local_assist/launch.py`.
- **Version parity and CI hardening (`local_assist/__init__.py`, `local_assist/server.py`, `package.json`, `scripts/models`, `.github/workflows/ci.yml`)**: Unified version `0.1.3` across `local_assist.__version__`, `SERVER_INFO["version"]`, `package.json`, and `./scripts/models --version`, added `persist-credentials: false` and full `unittest` suite execution under PyYAML in `.github/workflows/ci.yml`, set `ram_gb_estimate: 18` on `qwen3-30b-a3b-2507-mlx-4bit`, and gitignored `.models.yaml.lock` and `.models-sync-*.yaml`.

## [0.1.2] - 2026-11-06

### Security and Unattended Worker Sandboxing
- **Configurable worker security profile (`local_assist/security_profile.py`, `scripts/opencode-local`, `scripts/opencode-attested`)**: Added `--security-profile <path>`, `--unattended-worker`, `--read-root`, `--write-root`, `--protect-path`, `--allow-tool`, `--deny-tool`, `--allow-mcp-tool`, `--deny-mcp-tool`, `--allow-subagents`, `--allow-ssh-agent`, `--allow-localhost-port`, `--pass-env`, `--keep-worker-home`, and `--allow-opencode-version-drift` so supervisors (such as `AgentComms`) can launch unattended OpenCode workers with both OpenCode runtime enforcement (`permission` catch-all `"*": "deny"`, fail-closed MCP tool allowlists, disabled native subagents) and macOS Seatbelt (`/usr/bin/sandbox-exec`) kernel enforcement.
- **Two-tier Seatbelt process isolation, immutable staged `local_assist` runtime, and authenticated loopback token relay (`_WorkerTokenRelay`)**: Used `(process-path "<opencode_real>")` + `process-exec` gating in `worker.sb` so child `shell` commands cannot re-exec `opencode` or connect to loopback inference/MCP ports (`8080`, `8081`, `9081`, `49374`). When `mcp.enable_local_assist: true`, provisioned a dedicated read-only Mach-O copy `<isolated_home>/bin/local-assist-python` (`0500`) and a self-contained read-only runtime snapshot `<isolated_home>/runtime` (`0400`/`0500`, bound via `local_assist_runtime.pth` and launched with `-I -m local_assist.server` and `PYTHONSAFEPATH=1`) so only `local-assist-python` can reach `localhost:8080` and never imports worker-writable code. Added an unsandboxed parent-process loopback HTTP relay in `scripts/opencode-attested` worker mode (`worker-relay-<hex>` constant-time bearer auth, `max_tokens` clamping, request/byte caps, and finite positive `max_session_usd` enforcement rejecting `NaN`/`inf`) so `se-session-*` tokens never enter `opencode.json` or the worker sandbox.
- **Default-deny `.git` and runtime write protection, minimal 6-service `mach-lookup` allowlist, and descriptor-pinned lifecycle/reaping**: Restricted `.git` writes under every `write_root` to explicit working-tree plumbing paths (blocking `.git/hooks`, `.git/config`, `.git/commondir`, `.git/rebase-merge`, and `.git/rebase-apply` and protecting sibling `.home` worker directories), write-protected `free-inference` runtime code/scripts/config/venv/Python installation paths even inside containing `write_roots`, removed `com.apple.trustd*` and `com.apple.cfprefsd*` from `(allow mach-lookup ...)`, set neutral `worker <worker@local>` git identity defaults, and added process-group + multi-pass start-time-revalidated reaping (`run_worker_sandbox_lifecycle`, `.unconfirmed-process-group.json`, fail-closed `lsof` observer checks), nonblocking `O_NONBLOCK` + `S_ISREG` + size-capped + row-deduplicated log harvesting, and descriptor-pinned `openat`/`unlinkat`/`fchmod` tree removal (`_safe_rmtree_nofollow`).

## [0.1.1] - 2026-11-03

### Security and Hardening
- **Process start-time (`lstart`) binding across lifecycle scripts**: Recorded `pid_lstart` and `upstream_pid_lstart` (`LC_ALL=C TZ=UTC ps -p <pid> -o lstart=`) in PID files, refused legacy records lacking start-time metadata across `serve-model`, `verify-served-model`, `with-session-token`, and `stop-model` (with explicit `--force-legacy` and record-level `--discard-legacy` recovery flags on `stop-model`), and withheld `SIGKILL` escalation if escalation-time `lstart` cannot be verified, preventing PID-reuse signaling races.
- **Environment allowlisting in `serve-model`**: Restricted child environments for `mlx_lm server`, `tinfoil-proxy`, and `se-key-proxy` to explicit safe allowlists (`BASE_SAFE_ENV_ALLOWLIST`), forcing `HF_HUB_OFFLINE=1`, `TRANSFORMERS_OFFLINE=1`, `HF_HUB_DISABLE_TELEMETRY=1`, and `DO_NOT_TRACK=1` by default on Rung 1.
- **Session cap and context clamping on proxy attachment**: `scripts/opencode-attested` now rejects attaching to proxy sessions whose caps exceed the launcher ceiling or explicitly passed CLI cap flags, requires `max_request_bytes >= 65536`, and clamps `output_limit` and `context_limit` to the active session's caps. Also set `scripts/serve-model --max-tokens-cap` default to `4096`.
- **`se-key-proxy` binary `CDHash` preservation and lexical ancestor walk**: Updated `build_se_key_proxy` in `local_assist/se_key.py` to preserve an already-verified `bin/se-key-proxy` release binary (avoiding unnecessary rebuilds that change the ad-hoc `CDHash` and trigger macOS Keychain partition ACL password prompts), and updated `verify_root_owned_binary_and_ancestors` to reject `.` and `..` segments and walk lexical path components with `os.lstat` before `.resolve()`.
- **JSON config escaping**: Escaped all string placeholders in `opencode-local`, `opencode-attested`, and `opencode-smoke` config renderers.
- **Prompt redaction in `local_assist` telemetry**: Redacted raw `text` in `compress_context` and `extract_fields` JSONL telemetry logs (`text_chars` + `text_sha256`, `redact_prompt=True`).

### Reproducibility, Testing, and Documentation
- **Committed evaluation evidence (`docs/evals/*.json`)**: Added `eval_evidence_artifact` to `models.yaml` for cleared models (`qwen3-30b-a3b-2507-mlx-4bit` and `tinfoil-deepseek-v4-1-flash`) and `scripts/generate-eval-manifest` (`--all`, `--check`, and `--offline-ci`) with `tests_sha256` and `suite_spec_sha256` digests, `evaluated_provider_config`, per-case pass/fail records, and strict `operator_exception` validation.
- **`_MiniYamlParser` YAML 1.2 parity**: Aligned folded block scalar (`>` / `>-`) line-joining with PyYAML, decoded quoted mapping keys, fixed mid-word apostrophe handling in comment stripping, and rejected unconsumed trailing input, unsupported YAML tags, anchors, flow collections, and YAML 1.1 boolean words.
- **Pinned dependencies and CI**: Added `requirements.txt`, SHA-pinned `.github/workflows/ci.yml` (`macos-15` hardware/e2e job + `ubuntu-latest` `verify-linux-portable` job), `SECURITY.md`, `CONTRIBUTING.md`, and `tests/__init__.py`.
